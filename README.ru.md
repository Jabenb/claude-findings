# Findings для Claude Code

[English](README.md) | Русский

После ревью, аудита или расследования Claude обычно оставляет в чате список: «тут баг, потому что то и это». Если ты не читал этот код, такой список мало что говорит. Findings переносит находки на страницу в браузере, где каждая находка — отдельная карточка, понятная сама по себе:

- **По-простому**: одно-два предложения без имён классов и жаргона.
- **Как это ломается**: живой пример из 3–6 шагов с настоящими значениями (id, время, сумма, поле и его значение), шаг с поломкой выделен красным.
- **Кто и как заметит**: гость, владелец, поддержка, бухгалтерия, и когда они это увидят.
- **Где**: файл и строка, копируются по клику.

В коде ничего не меняется, пока ты не скажешь. **Чинить** сначала просит у Claude решение, и оно появляется в той же карточке: что изменится простыми словами, тот же пример после исправления, дифф по файлам с подсветкой синтаксиса и что решение не закрывает. Правка начинается только по кнопке **Применить**.

Страница работает на [Claude Hub (webhub)](https://github.com/jabenb/claude-webhub): хаб её хостит, обновляет вживую и передаёт нажатия обратно в сессию.

## Что можно сделать с находкой

| Кнопка | Что происходит |
|---|---|
| **Не понял, проще** | Claude объясняет ещё раз, проще. Ответ приходит сбоку, без чата; прежние объяснения остаются, между ними можно переключаться. |
| **Другой пример** | Та же проблема на другом сценарии с другими данными. |
| **Чинить** | Claude читает нужное и показывает решение в карточке. Код пока не меняется. |
| **Применить** | Claude правит код, проверяет и отмечает находку исправленной, с тем, чем проверил. |
| **Другой вариант** | Ещё одно решение, не похожее на уже показанные; все остаются в карточке. |
| **Обсудить в чате** | Вставляет цитату находки (и решения) в поле ввода чата, для твоего вопроса. |
| **Отложить** | Находка уходит в «Отложенные», и каждое твоё сообщение напоминает Claude её не трогать, пока ты её не вернёшь. |
| **Не проблема** | Закрывает находку без исправления. |

К любому действию можно дописать уточнение в поле над кнопками, оно уйдёт вместе с ним («без миграций», «а что такое type?»).

Список делится на **Ждут тебя**, **Отложенные** и **Закрытые**; закрытые убираются разом (с отменой). Есть поиск, фильтр по серьёзности, история по каждой находке и боковая колонка: что Claude держит в памяти и что ушло ему со страницы.

Клавиши: `J`/`K` следующая и предыдущая, `⌘↵`/`Ctrl+↵` чинить или применить, `S` проще, `E` другой пример, `D` отложить, `X` не проблема.

## Что нужно

- [Claude Hub (webhub)](https://github.com/jabenb/claude-webhub) в той же области установки и Docker для его сервера.
- Сборка Claude Code с модами (плагины с hooks-модулем).
- Браузер с доступом в интернет для подсветки кода (см. ниже). Без него страница работает, код показывается без цветов.

## Установка

В поле ввода сессии Claude Code:

```
/plugin install webhub --marketplace jabenb/claude-webhub
/plugin install findings --marketplace jabenb/claude-findings
```

Из терминала:

```bash
claude plugin install webhub --marketplace jabenb/claude-webhub
```

```bash
claude plugin install findings --marketplace jabenb/claude-findings
```

Чтобы поставить только для одного репозитория, добавь к обеим командам `--scope project` или `--scope local`. Если мод уже загружается из папки (`--plugin-dir`, `CLAUDE_CODE_PLUGIN_DIRS` или папка модов сессии), убери её, иначе он загрузится дважды.

## Как пользоваться

1. Попроси Claude сделать ревью, аудит или расследование. Если находок две и больше, Claude вызывает инструмент `report` вместо списка и одной строкой пишет, что находки на странице, с её адресом.
2. `/findings` в любой момент показывает адрес страницы. В хабе страница видна и под названием сессии, с числом находок, которые ждут тебя.
3. Разбирай карточки. Нажатие уходит Claude сообщением от твоего имени; «Проще» и «Другой пример» отвечаются сбоку и в чат не попадают, если только быстрый ответ не сорвался.

Пока N находок ждут тебя, в строке статуса горит `Находки: N`.

## Языки

Страница следует языку, выбранному в хабе: английский, русский или украинский. На том же языке уходят и сообщения Claude от кнопок. Сами находки Claude пишет на языке, на котором ты с ним говоришь.

## Подсветка кода

Диффы в решениях подсвечивает [Shiki](https://shiki.style) 4.5.0: страница грузит его с `esm.sh` (версия закреплена, движок регулярных выражений на JavaScript, грамматики подгружаются по расширению файла: PHP, Blade, TypeScript, Python, SQL, YAML, Go и другие). Цвета — тема [Islands Dark](https://github.com/bwya77/vscode-dark-islands) от bwya77 (MIT), она лежит внутри мода и используется в обеих темах страницы. Лигатуры в коде выключены, так что `->`, `===` и `=>` видны как написаны.

## Ничего не мигает

Страница никогда не перерисовывает экран целиком. Каждая отрисовка вливается в DOM узел за узлом: переключение групп, открытие карточки, листание объяснений и решений или новое состояние от Claude меняют только то, что изменилось. Уточнение, которое ты набираешь, сохраняет текст и курсор, пока страница обновляется, а новый дифф подсвечивается до показа, так что код не вспыхивает из серого в цветной.

## Где хранятся данные

Всё лежит в `~/.claude/mods-data/findings/` (внутри `$CLAUDE_CONFIG_DIR`, если он задан); в репозитории проекта ничего не появляется:

- `sessions/<id сессии>.json`: находки сессии, объяснения, решения и история, чтобы страница вернулась после перезапуска или `--resume`. Файлы, которые не трогали 30 дней, удаляются раз в сутки.
- `projects/<путь проекта>.json`: находки, которые ещё ждут тебя, по git-веткам. Другая сессия на той же ветке тоже их показывает с пометкой «Из другой сессии»; раз она не читала этот код, её запросы несут саму находку.

Находки ветки, удалённой локально, забываются через 30 дней после последнего изменения. Хаб хранит и свою копию состояния страницы.

Мод раньше назывался «Разбор» (razbor). При первом запуске он копирует данные из `~/.claude/mods-data/razbor/`, если новой папки ещё нет; файлы прежней версии с боковой панелью читаются как есть. Названия инструментов теперь `mcp__findings__*`.

## Для Claude

Мод добавляет правило в системный промпт и три инструмента:

- `mcp__findings__report`: показать находки или новое объяснение существующей (`id`). Конкретные значения в примере оборачиваются в `{{двойные скобки}}` и выделяются в карточке.
- `mcp__findings__propose_fix`: показать решение в карточке до любых правок.
- `mcp__findings__mark_fixed`: отметить находку исправленной после правки, с `check`: чем проверено.

## Разработка

```bash
claude plugin validate .
```

```bash
claude plugin test .
```

- `hooks/model.ts`: разбор входа, состояние и его изменения, тексты сообщений (чистые функции).
- `hooks/register.ts`: движок и хаб: инструменты, цикл прослушивания, нажатия, файлы.
- `hooks/page/page.ts`: вся страница; `hooks/page/theme.ts`: Islands Dark.
- `tests/findings.test.ts`: модель и мод целиком, с хабом и движком в памяти.

## Удаление

```bash
claude plugin uninstall findings
```
